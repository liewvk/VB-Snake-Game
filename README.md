# VB Snake Game

This repository contains a classic Snake game implementation built with Visual Basic .NET, based on the project from VB Game Programming Chapter 22.

## Overview

The game is a simple arcade-style Snake clone where the player controls a growing snake, collects food, and avoids crashing into the walls or itself. It is designed as a beginner-friendly Visual Basic project and demonstrates core game-loop and rendering concepts.

## Features

- Classic Snake gameplay
- Keyboard controls
- Increasing difficulty as the snake grows
- Collision detection with walls and body
- Simple game loop and rendering logic
- Written in Visual Basic .NET

## Controls

- Arrow keys: move the snake
- Escape: quit the game
- Enter: start or restart the game (if implemented in the project)

## Getting Started

1. Open the solution file in Visual Studio.
2. Restore NuGet packages if prompted.
3. Set the startup project to the game project.
4. Press F5 to build and run.

## Project Structure

- `VB Snake Game` / project files
- `Form` and game logic source files
- Graphics and UI-related code for the game board

## Notes

This project is intended as a learning exercise and example for Visual Basic game development. You can extend it with sound effects, a score system, levels, or touch controls.
